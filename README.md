# KP4 Lipidomics R Scripts


## Overview

This repository contains R scripts and processed input files used for oxidized phospholipid (OxPL) analysis. The workflow includes conversion of LPPtiger output files, quality control visualization, Kendrick mass defect analysis, Fenton/H2O2-reference analysis, ML210-treated KP4 lipidomics analysis, clustering, PCA, heatmap visualization, and BODIPY C11 correlation analysis.

## Main analysis modules

### 1. LPPtiger library conversion

`Codes/1. LPPtiger/Conversion of Json to MSP.R` converts LPPtiger-generated JSON output into MSP and CSV formats for downstream OxPL identification and spectral library construction.

Main outputs:

- `Output/KP4_All_PL.msp`
- `Output/KP4_All_PL.csv`

### 2. Quality control and KMD analysis

Scripts in `Codes/2. QC and KMD plot/` generate quality control plots and Kendrick mass defect visualizations.

These scripts include:

- Peak area QC across pooled QC injections
- Retention time stability QC
- Hydrogen-based Kendrick mass defect analysis to compare oxidized lipids with their non-oxidized precursor lipids and inspect potential in-source fragmentation features

### 3. Fenton and H2O2 reference analysis

Scripts in `Codes/3. Fenton+H2O2/` process oxidized lipid reference datasets generated by Fenton reaction and H2O2-only treatment.

The analysis includes:

- Data preprocessing and normalization
- Missing value imputation
- Venn diagram 
- Extracted ion chromatogram visualization
- MS/MS spectrum visualization
- Heatmap visualization of reference OxPLs
- PCA analysis of oxidized and non-oxidized lipids
- K-means clustering of OxPL accumulation patterns

### 4. ML210-treated KP4 lipidomics analysis

Scripts in `Codes/4. ML210/` process lipidomics data from ML210-treated KP4 cells.

The analysis includes:

- Lipid quantification and normalization
- OxPL identification coverage comparison
- PCA analysis of non-oxidized lipids and OxPLs
- K-means clustering of ML210-induced OxPL changes
- Heatmap visualization of clustered OxPLs
- Cell viability analysis
- Overlay and correlation analysis between OxPL abundance and BODIPY C11 lipid peroxidation measurements

## Notes

- File paths are written relative to the project root.
- `.Rdata` and `.rds` files in `Output/` are used as intermediate files for downstream visualization scripts.
- `KP4_All_PL.json` is provided as a compressed ZIP file due to GitHub file size limitations. Please unzip `KP4_All_PL.zip` before running the R scripts.
